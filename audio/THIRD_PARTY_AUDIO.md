## Optional sounds (not bundled)

Three autumn sounds are read from this directory if they are present and are simply silent if they
are not. Drop a file in with one of these base names and any of the extensions `.ogg`, `.wav` or
`.mp3`:

| Base name | Used for |
| --- | --- |
| `wind_gust` | The wind during a gust. Should loop; its volume and pitch rise and fall with the gust. **If absent, the mod synthesises a wind bed instead** - filtered noise with a slow swell - so this slot is only worth filling if you prefer a recording. |

Volumes are under `[Nature ambience]` in the config file and in the F11 menu.

If you add files here, record their source and licence below in the same form as the entries above.
